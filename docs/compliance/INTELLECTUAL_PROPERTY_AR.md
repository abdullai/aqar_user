# سياسة الملكية الفكرية

جميع المحتويات داخل المنصة محمية بموجب أنظمة الملكية الفكرية.

يشمل ذلك:

- الصور
- الشعارات
- العلامات التجارية
- التصاميم
- قواعد البيانات
- المحتوى النصي

## يمنع

- نسخ المحتوى
- إعادة النشر بدون تصريح
- استخدام العلامة التجارية بدون إذن
