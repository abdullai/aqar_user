# تكامل نفاذ

> **الحالة الحالية: غير جاهز للإنتاج.** المحتوى السابق ذكر أن التفعيل اكتمل
> وأن النظام آمن وجاهز، لكن لم يحدث نشر حقيقي أو اختبار مع Elm.

## المكونات الموجودة

- بوابة Node.js مستقلة لبدء الطلب والاستعلام واستقبال Callback.
- تحقق Callback باستخدام JWT موقّع بـ RS256 والتحقق من JWK.
- واجهة Supabase Edge Function تتصل بالبوابة، وترفض إنشاء جلسة وهمية.
- اختبارات محلية وإعدادات نشر مقترحة.

## المتطلبات المتبقية

- بيانات اعتماد Elm وقيم `iss` و`aud` ورابط JWK وعناوين Callback الرسمية.
- خادم داخل السعودية، عنوان IP ثابت، ونطاق مع HTTPS.
- ترحيل قاعدة البيانات المذكور في دليل النشر.
- قرار وتنفيذ موثوقان لربط هوية نفاذ بحساب التطبيق وإصدار جلسة Supabase Auth.
- اعتماد موقع تخزين بيانات الهوية واختبار التكامل مع Elm.
