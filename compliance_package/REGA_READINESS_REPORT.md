# جاهزية REGA — REGA Readiness Report

**التاريخ:** 2026-05-15

---

## ما هو موجود

- وثيقة تصميم: `compliance_package/REGA_INTEGRATION_DESIGN.md`
- في قاعدة البيانات/التطبيق: حقول **`rega_payload`** على العقارات، لقطات **`marketing_license_snapshot`**, منطق عرض أسماء المسوّقين من الحمولة (`rega_payload` → أسماء عرض)، وسياسات نشر مرتبطة بجودة البيانات.
- Edge: لا يوجد **عقد API رسمي** مُفعَّل بالكامل في المستودع المراجعة — التكامل الحقيقي يتوقف على مفاتيح وعقود الهيئة.

---

## ما هو الناقص للربط الرسمي

1. **مصادقة الطلبات** (OAuth / مفاتيح / IP allowlist) حسب دليل الهيئة.
2. **نموذج بيانات ثابت** للاستجابة (وليس JSON حر فقط) + تخزين **توقيع/مرجع تحقق** إن طُلب.
3. **مزامنة دورية** للترخيص المرتبط بالإعلان (رقم إعلان REGA) مقابل حالة الإعلان في المنصة.
4. **سياسات RLS** لأي جدول جديد يخزّن استجابات REGA الخام (قراءة للمالك/الموظف المصرّح فقط).
